# Open Adventure for GFOS

The AmiCradle Team's port of Open Adventure (Colossal Cave Adventure 2.5,
Crowther and Woods, forward-ported by Eric S. Raymond) to GFOS: AmigaOS 3.2
with GFOpenUp, 68040/68060, in a console window. It ships as a release
archive with an Installer and as the GFOpenUp part Parts/OpenAdventure.

Upstream is fetched at build time (package/openadventure.lock); this
repository holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
